TUNEPRO - INSTALLATIONSANLEITUNG
====================================

SCHRITT 1: Vorbereitung
------------------------------------
Entpacke die ZIP-Datei vollstaendig auf deinem PC. Du erhaeltst einen Ordner
"scooter-tune" mit index.html, manifest.json, sw.js und den Unterordnern
css, js, i18n, icons.

SCHRITT 2: Hosting (kostenlos, GitHub Pages)
------------------------------------
1. In deinem bestehenden Repository "scooter-tune" zuerst die alte
   ZIP-Datei und alte fehlerhafte Dateien loeschen (falls vorhanden).
2. "Add file" -> "Upload files" -> ALLE Dateien und Unterordner aus dem
   entpackten Ordner "scooter-tune" hochladen (index.html muss direkt im
   Hauptverzeichnis liegen, NICHT als ZIP und NICHT in einem weiteren
   Unterordner).
3. Commit klicken.
4. Settings -> Pages -> Branch "main", Ordner "/ (root)" -> Save.
5. Nach 1-2 Minuten ist die App unter deiner Pages-Adresse erreichbar,
   z.B. https://deinname.github.io/scooter-tune/

SCHRITT 3: App auf dem Handy oeffnen
------------------------------------
- Android: mit Chrome oeffnen.
- iPhone: mit Safari oeffnen (Pflicht fuer die Installation).

SCHRITT 4: Icon auf den Homescreen
------------------------------------
Android (Chrome): Installations-Banner bestaetigen oder Menue (drei Punkte)
-> "App installieren".

iPhone (Safari): Teilen-Symbol -> "Zum Home-Bildschirm" -> "Hinzufuegen".

SCHRITT 5: Nutzung
------------------------------------
Icon antippen. Die App oeffnet sich im Vollbild ohne Adressleiste.
Alle Funktionen sind rein visuell und speichern nur lokal im Browser.
Standardsprache ist Englisch, Deutsch ist vollstaendig uebersetzt und im
Zahnrad-Menue unter "Language" waehlbar.
