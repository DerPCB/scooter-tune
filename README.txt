INSTALLATION:
1. Entpacke diese ZIP-Datei auf deinem PC.
2. Lade den Inhalt des Ordners "scooter-tune" direkt ins Hauptverzeichnis deines GitHub-Repos hoch.
3. Commit -> Settings -> Pages -> main / (root) -> Save.
4. https://derpcb.github.io/scooter-tune/ im Smartphone aufrufen und zum Startbildschirm hinzufügen.
