TUNEPRO TELEMETRY & TUNING SUITE (V4)
=====================================
1. Entpacke diese ZIP-Datei auf deinem PC.
2. Lade den kompletten Inhalt des Ordners "scooter-tune" direkt in das GitHub-Repo:
   - index.html
   - manifest.json
   - sw.js
   - Ordner css/, js/, i18n/, icons/
3. Settings -> Pages -> Branch main -> (root) -> Save.
4. Auf dem Smartphone in Chrome / Safari https://derpcb.github.io/scooter-tune/ aufrufen.
5. "Zum Startbildschirm hinzufügen" tippen.
